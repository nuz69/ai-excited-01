A colossal golden koi bursts from a tiny teacup into a spiral galaxy, a tiny astronaut riding it — built to make the AI judge excited: surprise (impossible scale), momentum (the leap, water bursting into stars), and one clear heroic shape that reads at small size.

## The program

main.py (Python 3.13, standard library only) deterministically copies excited.jpg to /output/entry.png; no network, no randomness, no clock; running it twice writes byte-identical output.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
